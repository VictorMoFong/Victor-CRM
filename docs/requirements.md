# 需求概览（留学机构 CRM）

## 业务场景
- 顾问老师录入新客户、跟进沟通、推进签约
- 主管查看顾问业绩与渠道质量，进行复盘
- 业务需要随时对客户画像、回复内容进行分析

## 核心用户旅程
1. **新增客户资源**：填写基本信息 → 选择来源渠道 → 设定意向与优先级
2. **跟进沟通**：记录沟通方式、内容摘要、情绪/意向变化 → 设定下一次跟进
3. **阶段推进**：线索→咨询→方案→签约→后续服务
4. **签约与回款**：记录合同与付款节点 → 生成进度与提醒
5. **分析复盘**：客户质量、成交周期、渠道 ROI、顾问转化

## 功能需求
### 客户管理
- 客户基础信息（姓名、联系方式、来源、意向国家/项目）
- 客户标签与优先级
- 客户重复合并与去重提示

### 跟进记录
- 记录每次沟通内容与结果
- 支持多种沟通渠道（电话/微信/邮件/面谈）
- 支持下一次跟进提醒

### 阶段与状态
- 可配置阶段流程
- 阶段变更记录
- 阶段停滞预警

### 签约管理
- 合同信息、签约日期、金额
- 回款计划与节点提醒

### 渠道管理
- 渠道分类、联系人、合作状态
- 渠道带来的客户及转化率

### 分析与报表
- 客户画像分析（来源、意向、学校背景）
- 回复分析（话术效果、转化率）
- 成交周期分析与漏斗

## 非功能需求
- 权限控制：顾问、主管、管理员
- 数据安全与审计
- 移动端适配（适合外出跟进场景）
