# Victor CRM（留学机构销售顾问版）

本项目提供一套面向留学机构销售顾问的 CRM 需求说明与信息架构蓝图，覆盖客户资源录入、跟进记录、签约管理、渠道开发与数据分析等核心场景。当前阶段以需求与数据模型为主，便于后续快速落地为 Web/移动端系统。

## 目标用户
- 留学机构销售顾问/咨询老师
- 业务主管/校区负责人

## 核心价值
- **客户资源沉淀**：每新增客户都能快速录入并统一管理
- **全过程跟进**：所有沟通记录、阶段进展可追溯
- **签约与转化分析**：查看转化率、渠道质量与顾问效率
- **可分析、可复盘**：支持客户画像与沟通质量分析

## 主要模块
1. **客户资源管理**：客户基础信息、意向国家/项目、来源渠道、优先级
2. **沟通与跟进**：多渠道沟通记录、提醒、下一步计划
3. **进展阶段管理**：线索→咨询→方案→签约→后续服务
4. **渠道与合作方管理**：渠道分类、合作状态、回款/成本
5. **签约与合同**：合同信息、付款进度、关键节点
6. **数据分析**：客户分析、回复分析、渠道分析、顾问业绩

## 使用方式（后续落地）
- 录入客户 → 自动进入线索池
- 每次沟通记录并自动更新时间线
- 到期提醒与待办，辅助推进签约
- 仪表盘查看客户画像、转化、成交周期
